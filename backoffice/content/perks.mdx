The Perks module — known as **Vantagens** in the app — is where you manage the exclusive discounts, promotions, and partner offers available to all MyEdenred users. Every perk you publish here appears in the Perks section of the app and web portal, visible to every registered user regardless of which Edenred product they hold. This catalogue is one of the most visible benefits of the MyEdenred platform, so keeping it current, well-organised, and accurate directly impacts user engagement and satisfaction.

## Access

The Perks module is available to users with the **Administrator** or **Marketing** role.

---

## The Perks List

The main Perks screen lists all perks that have been created in the system.

The list table displays:

| Column | Description |
|---|---|
| **Logo** | The partner's circular logo image |
| **Discount type** | The type of promotion (for example, percentage discount, fixed amount, free item) |
| **Validity** | The active date range of the perk |
| **Title** | The perk headline as shown to users |
| **Summary** | A short promotional teaser |
| **Status** | Whether the perk is currently **Published** or **Suspended** |

Use the **search bar** to find a perk by name or partner, and use the **filters** to narrow the list by category or status.

## Creating a New Perk

<Steps>
  <Step title="Navigate to Perks">
    Go to **Content → Perks** in the Backoffice sidebar.
  </Step>
  <Step title="Click Create New">
    Select **Create New Perk**. The perk creation form opens.
  </Step>
  <Step title="Enter the perk details">
    Fill in the required and optional fields:

    | Field | Required | Description |
    |---|---|---|
    | **Title** | Yes | The short headline users see in the perks catalogue list (for example, *20% off at Galp fuel stations*) |
    | **Summary** | Yes | A one- or two-sentence teaser displayed in the catalogue card view |
    | **Discount type** | Yes | The nature of the promotion — percentage off, fixed discount, free product, etc. |
    | **Validity dates** | Yes | The start and end dates for when this perk is available. The perk automatically stops showing after the end date |
    | **Categories** | Yes | Assign the perk to one or more categories (for example, Food, Fuel, Shopping). Users can filter the perks catalogue by category |
    | **Partner logo** | Yes | A circular image of the partner's logo. This appears in the catalogue list and on the perk detail page |
    | **Featured image** | Yes | A rectangular banner image shown prominently on the perk detail page |
    | **Full description** | Yes | The complete perk description, redemption instructions, terms, and any exclusions. Supports HTML formatting including links |
    | **Call-to-action button 1** | Optional | Add a primary action button with a label and a deep link or external URL (for example, linking to the partner's website to claim the offer) |
    | **Call-to-action button 2** | Optional | Add a secondary action button if a second action is needed |
  </Step>
  <Step title="Set the status">
    Choose whether to **Publish** the perk immediately or **Save** it as a draft for later review before publishing.
  </Step>
  <Step title="Save">
    Click **Save**. Published perks appear in the app's Perks section immediately. Suspended perks are stored in the system but not visible to users.
  </Step>
</Steps>

<Tip>
  When writing the full description, draft your text in a plain text editor first and then add HTML formatting. Pasting directly from Microsoft Word can introduce invisible formatting characters that break the layout in the app.
</Tip>

## Editing a Perk

To update the details of an existing perk:

<Steps>
  <Step title="Find the perk">
    Locate the perk in the list using the search bar or filters, then click its name or row to open the detail view.
  </Step>
  <Step title="Click Edit">
    Select the **Edit** action. All fields become editable.
  </Step>
  <Step title="Make your changes">
    Update any field — title, description, images, validity dates, categories, or call-to-action buttons.
  </Step>
  <Step title="Save">
    Click **Save**. Changes to a published perk take effect in the app immediately after saving.
  </Step>
</Steps>

## Deactivating a Perk

When a promotion ends or a partner arrangement changes, deactivate the perk rather than deleting it. Deactivation removes it from the user-facing catalogue while preserving it in the Backoffice for future reference or reactivation.

To deactivate a perk, open the perk and select **Suspend**. The perk status changes to **Suspended** and it is removed from the app immediately.

To reactivate a suspended perk, open it and select **Publish**.

---

## Deleting a Perk

To permanently remove a perk, open its detail page and select **Delete**. You will be asked to confirm the action.

<Warning>
  Deletion is permanent. If there is any chance you may need the perk again in the future — for example, a seasonal offer that recurs annually — use **Suspend** instead of Delete. You can always duplicate a suspended perk to create a new version for next year.
</Warning>

---

## Duplicating a Perk

Use the duplicate action to create a new perk based on an existing one. This is the fastest way to set up a recurring promotion or a variant offer from the same partner.

Open the perk you want to copy and select **Duplicate**. A new perk is created in **Suspended** status with all the same content. Rename it, update the validity dates and description, then publish when ready.

## Managing Perk Categories

Categories allow users to filter the Perks catalogue in the app. You manage categories independently from individual perks.

<Steps>
  <Step title="Open the Categories panel">
    From the Perks screen, open the **Categories** section or modal (accessible via the manage categories button).
  </Step>
  <Step title="Create a new category">
    Click **Create** and enter the category name (for example, *Restaurants*, *Transport*, *Health & Wellness*). Save the category.
  </Step>
  <Step title="Edit a category">
    Click an existing category name to rename it. The updated name reflects immediately in the app filter and on any perks assigned to that category.
  </Step>
  <Step title="Delete a category">
    Select **Delete** on a category you want to remove. Before deleting, reassign any perks in that category to a different one, or they will no longer be linked to a visible category.
  </Step>
</Steps>

<Note>
  Perks are visible to **all MyEdenred users** regardless of which product they hold — Cartão Refeição, Cartão Flexível, Wallet Creche, or Wallet Educação. There is no per-product segmentation of perks. If a promotion is only relevant to users of a specific product, make this clear in the perk's description and title so users understand the context.
</Note>
